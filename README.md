# Emberline — AI Agent Business Landing Page

A sleek, single-file landing page for an AI agent business. Dark background with warm
orange accents. No build tools, no dependencies, no coding required.

## What's included

Everything lives in one file: `index.html`

- **Hero** with a live "agent dashboard" mockup and floating stat cards
- **Services** — voice/chat agents, workflow automation, lead gen, content, custom systems, managed support
- **How It Works** — the 4-step client journey
- **Results** — productivity and profitability stats
- **Industries** — 8 target customer segments
- **Testimonials**, **FAQ**, **Contact CTA**, and **Footer**
- Smooth scroll, fade-in animations, fully responsive (mobile-friendly)

## How to view it

Download `index.html` and double-click it — it opens in any web browser.

## How to put it online for free (GitHub Pages)

1. On this repository's GitHub page, click **Settings**
2. In the left sidebar, click **Pages**
3. Under "Branch", select your main branch and click **Save**
4. After a minute, your site will be live at the URL GitHub shows you

## How to customize

Open `index.html` in any text editor and search for the text you want to change:

- **Business name**: search for `Emberline` and replace it everywhere
- **Email address**: search for `hello@emberline.ai` and replace it
- **Colors**: at the top of the file, in the `:root` section, change `--orange` and
  `--bg` to any color you like
- **Testimonials, stats, FAQ answers**: the text is plain English — just edit it
